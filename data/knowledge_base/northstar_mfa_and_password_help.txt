Document: Password and Multi-Factor Authentication Help
Owner: Identity and Access Management
Audience: All Northstar employees
Last reviewed: September 2026

1. Password Reset

Northstar passwords expire every 90 days. Employees receive reminder emails beginning 14 days before expiry. A password must contain at least 14 characters and cannot reuse any of the previous 12 passwords. Passphrases are encouraged because they are easier to remember and meet the length requirement.

To reset a password, go to https://password.northstar.internal from any internet-connected device. Select Reset password, enter your short username, verify your enrolled MFA method, and create a new password. Password changes can take up to five minutes to reach SecureConnect VPN and Windows sign-in services.

If you have just changed a password, wait five minutes and then use the new password for VPN. Do not repeatedly use the old password: failed sign-ins can cause a temporary account lock.

2. Account Locked

An account is locked after five unsuccessful sign-in attempts in a 15-minute period. Wait 15 minutes before trying the correct password once. If access is urgent after the wait period, create a high-priority access ticket. Include the account username but never include the password.

3. Missing MFA Prompt

If the Northstar Authenticator notification does not arrive, first open the application manually and check for an approval request. Ensure the phone has internet access and notifications are enabled. Use the "Use a different method" option on the sign-in screen only if you have an approved backup method enrolled.

Common causes are a phone in airplane mode, disabled notifications, an expired application session, or incorrect phone date and time. Restarting the phone can resolve a stale notification connection. Do not approve an MFA request you did not initiate.

4. New Phone or Lost Phone

Employees changing phones should enroll the new device before erasing the old one. Go to https://identity.northstar.internal/security-info while signed in, choose Add sign-in method, and select Northstar Authenticator.

For a lost or stolen phone, report the incident to the IT service desk immediately. The service desk will remove the old MFA method after verifying identity through the approved process. This request should be marked high priority if the lost phone was unlocked or contains Northstar data.

5. When to Raise a Ticket

Raise an IT ticket when password reset, account unlock waiting period, and the available MFA recovery methods do not restore access. Include the system that is blocked, for example VPN, FinanceHub, Windows sign-in, or Git service. Include the exact message shown and whether an MFA prompt was received. Do not include a password, MFA code, recovery code, or personal identification document.
